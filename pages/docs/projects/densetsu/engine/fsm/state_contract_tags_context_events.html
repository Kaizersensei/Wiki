State Contract (Tags, Context, Events)

Overview

This page captures the current evidence for state contracts, tagging, and context events. The context database shows FSM core classes and a controller context object, but no explicit “state contract tag” registry or event schema.

Current evidence

  • engine/fsm/State.gd and engine/fsm/StateMachine.gd define state lifecycle and transitions.
  • engine3d/fsm/ControllerContext3D.gd provides refreshable runtime context for 3D states.

Likely integration points

  • Actor tag signals from ActorInterface3D may act as state gating signals.
  • Controller context data may function as a lightweight state contract.

Open questions

  • Is there a formal contract/tag schema for state transitions?
  • Are context events published through the EventBus or another channel?

Status

Unknown. No explicit contract/tag registry identified in the evidence set.
