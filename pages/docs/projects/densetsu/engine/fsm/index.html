FSM System

Overview

The FSM System defines how actor behavior is partitioned into states and how transitions are requested and executed. Evidence includes the core StateMachine and FSMState classes plus 3D controller context and locomotion states.

Scope

  • State registration and activation
  • Per-frame and physics state updates
  • Context objects used by controller-driven states
  • Movement and animation intent states

Pages

  • FSM System Overview — responsibilities and API surface.
  • State Contract Tags Context Events — current evidence and open questions.

Status

Implemented. Core FSM classes and example states are present in the evidence set.
