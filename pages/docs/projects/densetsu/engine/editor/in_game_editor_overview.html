In‑Game Editor Overview

Overview

Editor tooling is provided through the Densetsu tool suite and related addon helpers. The evidence set includes editor context menu plugins and helper utilities for asset processing.

Key tooling

  • addons/densetsu_tool_suite/plugin.gd — editor plugin entrypoint.
  • addons/densetsu_tool_suite/helpers/arraymesh_extract_helper.gd — mesh extraction.
  • addons/densetsu_tool_suite/helpers/fbx_anim_persist_helper.gd — animation import persistence.
  • addons/densetsu_tool_suite/helpers/image_transform_helper.gd — image path conversion.
  • addons/densetsu_tool_suite/helpers/mesh_obj_helper.gd — OBJ export helpers.

Related editor scenes

  • engine3d/tools/CharacterEditor3D.tscn

Status

Implemented. Editor tooling scripts and helper scenes are present.
