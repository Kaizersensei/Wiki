Combat Overview

Overview

The combat runtime centers on combat targets, attack FX handling, and projectile spawning. Evidence includes a combat target dummy for testing, an attack FX driver, and a projectile subsystem with templates and behaviors.

Core runtime elements

  • AttackFXDriver3D — links combat state to VFX or debug visibility.
  • CombatTargetDummy3D — test target with damage visualization and simple attack handling.
  • ActorProjectileSpawner3D — spawns subweapons and projectiles.
  • DensetsuProjectile3D — projectile runtime with hit + expire signals.

Hit + damage flow

  • Hit detection uses combat target areas and projectile hit callbacks.
  • Damage feedback is represented via target dummy visuals and type multipliers.

Data dependencies

  • data/stats — stats data.
  • data/status_effects — status effect definitions.
  • data/projectiles and data3d/projectiles — projectile templates.

Status

Implemented. Combat runtime scripts and projectile systems are present.
