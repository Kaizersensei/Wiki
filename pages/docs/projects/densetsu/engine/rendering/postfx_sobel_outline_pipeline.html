PostFX Sobel Outline Pipeline

Overview

The Sobel outline pipeline applies a post-processing outline effect using depth and composite passes. Evidence includes the Sobel outline depth post-FX and composite controller.

Pipeline components

  • SobelOutlineDepthPostFX3D.gd — depth pass and shader parameter application.
  • SobelOutlineComposite3D.gd — combines outline with the base frame.
  • SobelOutlinePostFX3D.tscn — scene wrapper for the outline effect.

Status

Implemented. Post-FX scripts and scenes exist in the evidence set.
