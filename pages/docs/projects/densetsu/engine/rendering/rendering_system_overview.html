Rendering System Overview

Overview

The rendering system includes custom post-processing nodes and shader utilities. Evidence highlights Sobel outline post-FX, toon post-FX controller, and shader helpers.

Key systems

  • SobelOutlineComposite3D — compositing for outline pass.
  • SobelOutlineDepthPostFX3D — depth-based outline post-processing.
  • ToonPostFXController3D — toon post-processing controller.
  • HandDrawnOutlinePostFX3D scene for outline rendering.

Shader utilities

  • shaders/wind/AutoAxisRange.gd — shader helper script.

Status

Implemented. Post-FX scripts and scenes are present.
