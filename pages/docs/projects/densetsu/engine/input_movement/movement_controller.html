Movement Controller

Overview

The movement controller resolves player input into actionable movement commands. It consumes input sources and movement profiles to drive locomotion state.

Key components

  • PlayerCommandResolver3D — builds command frames from input sources.
  • PlayerInputSource — player-controlled input source.
  • PlayerCommandFrame3D — command frame data.
  • MOVEMENT_Player_Default.tres — default movement profile data.

Data assets

  • data3d/movement/ — movement profiles.
  • data/movement/ — supporting movement data.

Status

Implemented. Movement controller scripts and data profiles are present.
