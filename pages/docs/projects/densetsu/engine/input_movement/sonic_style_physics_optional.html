The current repo does not implement a dedicated subsystem, flag, or runtime mode literally named sonic. This page title should be read as historical shorthand for optional high-mobility movement feel, not as the name of a standalone engine feature.

What Exists Instead

  • MovementData3D.gd exposes the tunable movement surface: walk, run, sprint, air control, jump and double jump, coyote time, jump buffer, wall jump, dash, roll, crouch, sneak-speed compatibility, slope limits, and fall handling.
  • The shell runtime routes those values through CharacterMotorModel3D when the modern shell path is active.
  • ActorMovementComponent3D preserves the same broad movement vocabulary for compatibility and fallback execution.

Optional Feel Tuning

  • MovementData3D contains a dedicated C2 Feel section for extra acceleration or deceleration shaping.
  • The shell motor exposes opt-in toggles such as dash_enabled, roll_enabled, posture toggle behavior, analog walk thresholds, and combat-lock movement rules.
  • This means the real optional surface is parameter-driven movement feel, not a single “enable Sonic mode” switch.

What The Title Should Not Imply

  • There is no verified SonicStylePhysics class, config, scene, or project setting in the inspected runtime tree.
  • The engine does not expose a separate movement subsystem that only applies to Sonic-like gameplay.
  • The current shell runtime also no longer treats Sneak as a distinct locomotion state; it resolves to Crouch or CrouchMove.

Best Current Reading

  • If the design goal is faster or more expressive arcade locomotion, work through MovementData3D, the shell motor exports, and the move catalog instead of looking for a named Sonic module.
  • If the goal is documentation cleanup, treat this page title as legacy wording that now maps to a broader movement-feel surface.

Validation

  • Targeted source checks across engine3d/ found no dedicated runtime surface literally named sonic.
  • MovementData3D.gd and CharacterMoveCatalog3D.gd provide the real current movement vocabulary and tuning surface.
  • docs/production_rewrite_worklog.md records the modern shell locomotion path in terms of character motor, move catalog, gait separation, dash or roll, wall jump, and crouch handling rather than any named Sonic system.
