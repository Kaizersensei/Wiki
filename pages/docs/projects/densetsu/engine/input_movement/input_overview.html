Input Overview

Overview

The input system abstracts player commands behind an input source interface and command frame model. This keeps gameplay logic independent from raw device input.

Core interfaces

  • IInputSource — provides movement vectors and action flags.
  • PlayerCommandFrame3D — records resolved command states per frame.
  • PlayerCommandResolver3D — converts input source signals into command frames.

Input actions

  • Move vector and side-scroller vector.
  • Jump pressed/just-pressed/just-released.
  • Run, modifier, dash, crouch toggles (see PlayerInputSource and NullInputSource).

Status

Implemented. Input source interface and resolver scripts exist.
