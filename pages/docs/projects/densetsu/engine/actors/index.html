Actor System

Overview

The Actor System defines how playable characters, NPCs, and world entities are represented and updated. Core evidence includes the ActorInterface3D base, ActorCharacter3D, and concrete actor scenes for player, NPC, and scenery.

Scope

  • Actor interface lifecycle hooks
  • Character actors (player, NPC)
  • Scenery actors
  • Actor parameters and tags

Pages

  • Actor System Overview — responsibilities and interfaces.
  • Actor Types Lifecycle — common lifecycle phases and state changes.
  • Creatures As Actors Framework — how creature/NPC actors are structured.

Status

Implemented. Actor base classes and concrete actor scenes are present in the evidence set.
