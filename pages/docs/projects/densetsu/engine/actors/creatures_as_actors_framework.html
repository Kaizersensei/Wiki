Creatures as Actors (Framework)

Overview

Creatures are implemented as actors built on the shared character actor stack. The NPC actor class provides common runtime behavior such as wander phases and animation updates.

Core classes

  • ActorCharacter3D.gd — base character actor.
  • ActorNPC3D.gd — creature/NPC behavior layer.
  • ActorParams3D.gd — actor parameters resource.

NPC runtime behavior

  • Wander cycle helpers: _update_wander_phase, _begin_wander_phase, _get_random_phase_duration.
  • Direction helpers: _get_random_horizontal_direction.
  • Motion + animation updates: _apply_wander_motion, _update_wander_animation.

Integration points

  • Actors emit lifecycle and tag signals from ActorInterface3D.
  • Movement states and controller inputs attach via the FSM and input systems.

Status

Implemented. NPC and character actor scripts are present with wander helpers.
