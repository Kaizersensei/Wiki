Game Identity

Title: Densetsu. Genre: Metroidvania / Narrative Action Adventure. Core Engine: Godot-based FSM & Actor System. Themes: Balance, Memory, Time, Renewal. Tagline: 'Swords, Sorcery and Shuriken'. Narrative: Michio heals anomalies born of the Great Eclipse; time observed, not mastered.

Core Loop

Pillars: Observation → Action → Reflection. Core loop: explore anomalies/regions; engage via combat/puzzles/environment; return to rest points to stabilize experience and progress.

Work Policies

AI Good: ideation, structuring, coding with plans; AI Bad: unreviewed production content, >50% unreviewed AI output, consumer-facing AI art/writing. Human review mandatory.

Deterministic Design

Deterministic design: minimize unknowns with defined parameters; certainty over probability; scientific + risk-based; reduce complexity; clear mapped implementation path.

Loop Application

Pillars Observation → Action → Reflection tie directly to runtime, actors, FSM, stats, and editor flows; use Rest Points to stabilize experience and progression.

Open questions / conflicts

Open: hierarchy between time rifts and anomalies not locked; naming conventions (full names vs given names) not fully locked. Time travel remains non-player-controlled; chat canon overrides docs.
