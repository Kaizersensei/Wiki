Planned Direction

  • Keep one deterministic runtime entry backed by manifest and catalog authority.
  • Reduce gameplay ownership inside ActorCharacter3D by moving stable domains toward shell components and service boundaries.
  • Finish the player-input cleanup so runtime labels, bindings, and locomotion semantics match the active shell path cleanly.
  • Replace the current animation bridge model with the documented torso or legs behavior architecture and curated palette workflow.
  • Expand the Authoring workspace from shell-plus-schema into a broader SQLite-backed authoring surface with compile outputs that stay runtime file-driven.
  • Layer biome semantics and deterministic generation on top of Terrain3D without making runtime query SQLite directly.

Reading Rule

  • If a page cites repo docs and code paths directly, treat it as a current-source summary.
  • If a page still says it is awaiting a direct source pass, treat it as backlog structure rather than implementation authority.
  • The documentation inventory is still useful as backlog, but parts of it reflect an older scan and should not outrank the June 2026 repo docs.
