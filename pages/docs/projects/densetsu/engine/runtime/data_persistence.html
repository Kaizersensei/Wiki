Data Persistence

Overview

Data persistence currently centers on Godot resources and structured data assets. The engine defines custom Resource classes and stores runtime data in data/ and data3d/ directories.

Resource schema

  • engine/data/resources/AIProfileData.gd
  • engine/data/resources/BiomeData.gd
  • engine/data/resources/CollisionData.gd
  • engine/data/resources/FactionData.gd
  • engine/data/resources/ItemData.gd

Runtime data assets

  • data3d/camera/CAMERA_Player_Default.tres
  • data3d/items/INVENTORY_Player_Default.tres
  • data3d/items/SUBWEAPON_Player_Default.tres

Status

Implemented. Resource schemas and sample assets exist in the evidence set.

Open questions

  • Long-term persistence (save slots, serialization strategy) is not documented here; see Save/Load.
