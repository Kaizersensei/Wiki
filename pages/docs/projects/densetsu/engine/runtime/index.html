Core Runtime

Overview

The Core Runtime section covers the startup path, scene lifecycle, input capture, and shared runtime services that keep the game loop moving. Evidence comes from the bootloader and loading screen stack, autoload singletons, and scene management scripts captured in the context database.

Scope

  • Bootstrapping and splash sequence
  • Loading screen lifecycle and progress reporting
  • Scene registration and runtime scene application
  • Autoload singletons (event bus, input manager, runtime)
  • Resource-backed data persistence

Pages

  • Bootloader Loading Splash Pipeline — Startup flow and splash sequencing.
  • Core Runtime Overview — Responsibilities and system map.
  • Data Persistence — Resource-backed data types and storage points.
  • Loading Screen Host And Content Slots — Loading screen host structure and visuals.
  • Save Load — Status and gaps for save/load workflows.
  • Startup Splashes Parameter Driven — Splash screen scenes and sequencing.
  • World Streaming — Current scene graph evidence and streaming gap.

Status

Implemented (partial). Boot and loading systems, autoloads, and scene management are implemented. Save/Load and World Streaming still need explicit evidence or a design decision.
