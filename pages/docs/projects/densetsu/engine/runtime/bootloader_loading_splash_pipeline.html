Bootloader / Loading / Splash Pipeline

Overview

The bootloader orchestrates the startup pipeline: it runs an initial boot sequence, plays startup splashes, resolves the target scene, and tracks loading progress.

Pipeline

  1. Bootloader initializes on scene ready.
  2. Startup splashes play in sequence (company logo, startup info).
  3. The target scene path is resolved (including command-line overrides).
  4. Loading screen starts and emits progress signals.
  5. On completion or failure, the bootloader transitions accordingly.

Key nodes & scripts

  • engine3d/loading/DensetsuBootLoader.gd — boot sequence orchestration.
  • engine3d/loading/DensetsuLoadingScreen.gd — loading screen host and signals.
  • engine3d/loading/DensetsuLoadingGauge.gd — visual progress display.
  • engine3d/loading/splashes/DensetsuSplashScreen.gd — splash base.
  • engine3d/loading/splashes/DensetsuCompanyLogoSplash.tscn
  • engine3d/loading/splashes/DensetsuStartupInfoSplash.tscn
