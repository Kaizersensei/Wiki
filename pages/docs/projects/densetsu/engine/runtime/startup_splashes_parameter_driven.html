Startup Splashes (Parameter-Driven)

Overview

Startup splashes are implemented as dedicated scenes and a shared splash screen base. The bootloader plays these scenes before main loading begins.

Known splash assets

  • engine3d/loading/splashes/DensetsuSplashScreen.gd — base splash script.
  • engine3d/loading/splashes/DensetsuCompanyLogoSplash.tscn
  • engine3d/loading/splashes/DensetsuStartupInfoSplash.tscn

Sequence

  • Bootloader triggers the splash sequence during boot.
  • Splashes complete before the loading screen begins.
