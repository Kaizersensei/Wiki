Loading Screen Host & Content Slots

Overview

The loading screen host is the runtime container for loading visuals and progress display. Evidence shows a loading screen node and a loading gauge node; specific “content slot” APIs are not confirmed in the current database.

Known elements

  • engine3d/loading/DensetsuLoadingScreen.gd — emits loading lifecycle signals.
  • engine3d/loading/DensetsuLoadingGauge.gd — draws progress bar and percentage.
  • engine3d/loading/DensetsuLoadingScreen.tscn — scene wrapper for the host.

Usage

  • Bootloader starts the loading screen during scene transitions.
  • Progress is reported through the loading screen signals.

Open questions

  • No explicit content-slot API was found in the evidence set.
  • Confirm whether additional content widgets are injected at runtime.

Status

Implemented (partial). Loading host and gauge exist; slot mechanics need verification.
