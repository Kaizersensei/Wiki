PathMeshInstance3D is an editor-facing node type that generates a mesh along a Path3D. In the Densetsu documentation wave it is tracked because designers can add it, configure it in the inspector, and regenerate geometry directly inside Godot.

When To Use It

  • Road, ribbon, tube, or cross-style meshes that need to follow a path.
  • Procedural authoring where shader data should receive path-length or around-the-mesh mapping channels.
  • Cases where manual mesh editing would be slower than adjusting path and width settings in the inspector.

Authoring Flow

  1. Create or select a Path3D.
  2. Add a PathMeshInstance3D node and assign the path_3d property.
  3. Choose a mesh format, subdivision strategy, width behavior, end behavior, and UV mapping outputs.
  4. Use the inspector Generate Mesh button to rebuild the mesh in place.

Review Notes

  • The upstream metadata in plugin.cfg is sparse, so internal docs should rely on the actual script behavior instead of the plugin manifest.
  • The generated mesh property is intentionally made read-only in the inspector by _validate_property().
  • This page documents the authoring surface, not the full mathematical internals of the generator. The property reference covers the concrete inspector contract.
