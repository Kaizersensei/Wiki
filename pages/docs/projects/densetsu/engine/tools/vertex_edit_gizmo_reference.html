Selection and Enable Flow

  • The plugin only considers MeshInstance3D nodes. Non-mesh nodes are ignored.
  • On selection change, the previous selected mesh has its edit-selected metadata cleared, and its enabled flag is reset to false.
  • If auto-enable is on, the newly selected mesh gets densetsu_vertex_edit_enabled = true immediately.
  • The status label explicitly tells the user whether a compatible mesh is selected and whether editing is active.

Save Flow

  • Save Edited Mesh only works when a MeshInstance3D with a mesh resource is selected.
  • The file dialog permits .tres and .res outputs only.
  • The current node mesh is passed directly to ResourceSaver.save; there is no separate export format.
  • The default output file name is <node_name>_edited.tres.

Limits and Review Notes

  • This tool does not present every vertex on dense meshes; it samples up to the configured handle count.
  • The editing surface is one mesh surface at a time. Wrong surface selection can look like missing handles.
  • Because edits are applied to a duplicated ArrayMesh, downstream scenes that still reference the original imported mesh will not automatically update unless the saved mesh resource is wired back in.
