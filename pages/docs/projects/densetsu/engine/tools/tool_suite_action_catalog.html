This page documents every visible Tool Suite action exposed from plugin.gd. It focuses on what a user can trigger, what the action touches, which settings feed it, and where the implementation lives.

Touchpoint legend:
  • Top menu means Tools > Densetsu > ....
  • Context means the Godot FileSystem dock right-click menu under Densetsu > ....
  • Scene selection means selected nodes in the 3D scene/editor selection.
  • FileSystem selection means selected files or folders in the FileSystem dock.

Scene Actions

New Densetsu Map Top menu You need a new map scene created from the project template instead of copying scenes by hand. Uses new_map_template_scene, new_map_output_dir, new_map_default_file, then opens a save dialog. Creates a new scene resource from the configured template path and writes it into res://. _on_tool_new_densetsu_map, _build_new_map_dialog, _on_new_map_file_selected

Select Nodes Intersecting Selected Mesh Top menu, scene selection You need to find mesh instances that physically overlap a reference mesh in world space. Requires a selected MeshInstance3D. Changes editor selection only. _run_select_intersecting_mesh_nodes, select_intersecting_mesh_helper.gd

Either reports candidates or mutates the active scene depending on dry-run state. _run_prune_occluded_mesh_instances, occlusion_prune_helper.gd

FileSystem Context Actions

The Tool Suite also installs a FileSystem context-menu plugin. It does not expose every top-menu action. The current coverage is:

Context submenu Actions exposed Notes
Densetsu > Geometry Pack to Static Mesh, extract mesh/material/combined variants, pivot reassignment, mesh-to-OBJ, subdivide mesh, scale mesh, flip model normals No scene-selection-only geometry actions are exposed here.
Densetsu > Textures Resize, flip/rotate, generate companion maps, cleanup companion maps, apply Terrain3D import standards Context cleanup/generation calls default to recursive folder handling where noted in labels.
Densetsu > Animation Enable Imported Animation Persistence Targets FileSystem-selected files/folders only.
Densetsu > Assets Replace Scene TRES/RES Refs with Selected OBJ, Move Selected To Folder... Used for asset-path workflows rather than scene-only bakes.
Densetsu > Maintenance Force Thumbnail Refresh (Selected) The broader maintenance actions remain top-menu only.

High-Risk Actions To Review Before Running

  • Scale Selected Mesh Files ... (Overwrite) rewrites selected resources in place.
  • Replace TRES_RES Mesh Refs With OBJ (Project-Wide) can rewrite large swaths of the project; start with dry run.
  • Cleanup Orphan .import Sidecars (Project) and companion cleanup actions remove files; confirm scope first.
  • Relink Missing Assets and build/git actions can alter repo state or produce publishable outputs.
  • Move Selected To Folder... changes resource paths; check downstream references after large moves.
