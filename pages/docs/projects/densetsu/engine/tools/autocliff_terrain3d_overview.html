Densetsu Autocliff is an editor-assisted placement tool for cliffs, rocks, and other placeable meshes. It samples either Terrain3D data or mesh-bearing scene targets, then scatters selected pool entries according to slope, height, density, clearance, and optional Terrain3D material filters.

What It Is

  • A project-owned editor plugin rooted at res://addons/densetsu_autocliff.
  • A dock-based workflow rather than a top-menu-only tool.
  • A placement system that supports both individual MeshInstance3D output and grouped MultiMeshInstance3D output.

When To Use It

  • You need fast cliff or rock population over a Terrain3D surface.
  • You want the same scattering logic on a mesh-derived target without requiring collision authoring first.
  • You need grouped placement tuning for large, medium, and small placeables instead of one global density rule.

Outputs and Ownership

  • Generated content is written under a named output root beneath the target's parent.
  • Mesh output can remain as editable instances or be converted into grouped MultiMeshInstance3D nodes.
  • The README and current tool behavior both treat generated nodes as Autocliff-owned placement output and identify them with the densetsu_autocliff tag/group.

Important Notes

Not Terrain3D-only: the current source explicitly supports mesh targets and descendant mesh sampling, so newer documentation should not describe this as a Terrain3D-exclusive tool.

Origin-sensitive: incorrect mesh pivots or embedded offsets are a common cause of bad placements.
