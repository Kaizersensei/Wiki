Autocliff Overview

Content status: Populated from local project notes. Final screenshot-driven workflow is pending UI/foliage overlap resolution.

At a glance

  • Densetsu Autocliff is an active, project-owned editor plugin at res://addons/densetsu_autocliff.
  • It places cliff/rock meshes (and other placeables) across selected Terrain3D or mesh surfaces using slope and placement filters.
  • It is used for fast environment dressing and can emit either individual MeshInstance3D output or MultiMesh output.

How it works

  • Enable the plugin in Project Settings and open the Autocliff dock.
  • Select either a Terrain3D node or a mesh-bearing Node3D target, then add placeable meshes.
  • Configure slope, density, offsets, placement, and output mode before generation.
  • Terrain3D targets use Terrain3D data sampling as the preferred path.
  • Mesh targets are sampled by triangle ray tests, including descendant mesh nodes under a selected root.

Interfaces

  • Plugin path: res://addons/densetsu_autocliff.
  • Plugin config: res://addons/densetsu_autocliff/plugin.cfg.
  • Primary in-editor surface: Autocliff dock.
  • Local implementation/reference doc: res://addons/densetsu_autocliff/README.md.

Operational concerns

  • Mesh-target sampling bypasses physics/collision requirements, which helps with imported geometry and temporary authoring meshes.
  • Placement quality depends on placeable mesh origins and embedded offsets; verify mesh origin before changing tool logic.
  • For dense output, prefer MultiMesh where possible.
