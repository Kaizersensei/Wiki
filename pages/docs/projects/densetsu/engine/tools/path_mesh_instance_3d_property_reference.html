Review Notes

  • The inspector plugin adds only one custom control: Generate Mesh. Everything else is driven by exported properties on the node itself.
  • Several exported properties rely on source defaults without explicit initializer values. Where the source does not set a value inline, this page labels them as source-default instead of guessing.
  • The UV mapping outputs are especially important for shader authors because they determine where path-derived scalar data is written.
