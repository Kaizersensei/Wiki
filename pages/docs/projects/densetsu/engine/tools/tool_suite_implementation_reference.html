This page is the code-facing companion to the action catalog. It describes the plugin registry, helper coverage, exported parameters, dialog surfaces, and the background jobs that actually do the work.

Architecture Summary

Surface Role Verification notes
plugin.gd Central registry for menu wiring, dialogs, exported settings, action dispatch, FileSystem context menus, and tool-log reporting. Verified.
_DensetsuSuiteContextMenuPlugin FileSystem context-menu surface for geometry, textures, animation, assets, and maintenance subsets. Verified in plugin.gd.
Helper scripts under helpers/ Batch operations for extraction, resize, image transforms, pivot changes, selection, subdivision, OBJ handling, and occlusion pruning. Mixed: several helpers are present, several are declared but missing.
External scripts under res://engine3d/tools/ Specialized pipelines for baking, git, build, optimization, and environment control map generation. Referenced by fixed script paths from Tool Suite.
Preview and confirmation dialogs High-parameter workflows for mesh baking, kitbash composite bake, project-wide mesh reference replacement, moves, and Poser conversion. Verified from dialog builder fields in plugin.gd.

Verification Gaps

Declared helper gaps: terrain3d_image_import_helper.gd, mesh_to_csg_helper.gd, import_sidecar_cleanup_helper.gd, missing_asset_relink_helper.gd, and mesh_flip_normals_helper.gd are referenced in plugin.gd but missing from the addon tree scanned on 2026-06-09.

Documentation rule: these actions remain documented because users can trigger them, but their helper-level implementation status must stay labeled source missing until the files exist.
