This page focuses on the code-level behavior behind the Autocliff dock: how state persists, how presets are stored, how placement samples are filtered, and how generated outputs are converted or cleared.

Plugin Shape

SurfaceRoleNotes
plugin.gdRegisters the dock with Godot and saves state on exit.The editor-plugin layer is intentionally thin.
autocliff_dock.gdOwns UI creation, persistence, presets, sampling, overlap rules, generation, output conversion, and cleanup.This is the real implementation surface.
README.mdOperator-facing notes and limits.Useful, but not exhaustive enough to replace source inspection.

State, Presets, and Persistence

Path or constantPurposeNotes
user://densetsu_autocliff_state.cfgPersistent dock stateWritten by save_state(), loaded by load_state().
res://temp/autocliff_presetsPreset storage directoryCreated on demand.
.cfgPreset file extensionOne preset per config file.
base_floor_medium_cliffBase preset nameUsed by reset/load bootstrap helpers.

Persistence is wired through _connect_persistence_signals(), which subscribes line edits, spin boxes, checkboxes, and option buttons to save-queue helpers. The dock does not save immediately on every change; it queues state writes through _queue_save_state() and _save_state_deferred().

Classification and Filtering Rules

Constant or modeMeaningCode notes
LARGE_OBJECT_MIN_METERS = 15.0Size threshold for large objectsUsed for group-based tuning previews and effective size grouping.
SMALL_OBJECT_MAX_METERS = 3.0Size threshold for small objectsObjects between thresholds are treated as medium.
MATERIAL_FILTER_MODE_BASE_OR_OVERLAYAccept either Terrain3D base or overlay IDDefault mode.
MATERIAL_FILTER_MODE_BASE_ONLYBase layer must matchTerrain-aware filter path.
MATERIAL_FILTER_MODE_OVERLAY_ONLYOverlay layer must matchTerrain-aware filter path.
MATERIAL_FILTER_MODE_DOMINANTDominant texture ID must matchMost restrictive terrain filter mode.

The dock classifies pool entries into large, medium, and small groups using measured bounds, then applies optional global and per-group multipliers to density, scale, bury depth, yaw, clearance, cluster radius, and slope windows.

Known Risks and Review Notes

  • Placement correctness depends heavily on the source mesh or scene origin. Mis-centered assets will look like Autocliff bugs even when the math is working.
  • Large sample areas with many pool entries can become expensive because each accepted placement goes through overlap and bounds logic.
  • The plugin treats Terrain3D as a first-class target, but mesh-target behavior is also implemented and should not be documented as Terrain3D-only anymore.
  • Preset storage under res://temp/ means presets are project content rather than user-only config; that is useful for sharing, but it also means they should be source-controlled intentionally.
