Export Options

OptionDefaultEffect
include_mesh_instancestrueInclude MeshInstance3D content under selected roots.
include_csgtrueAttempt to bake CSGShape3D trees into exportable meshes.
include_multimeshfalseExpand MultiMeshInstance3D data into regular geometry for export.
apply_world_transformtrueExport vertices in world space rather than local node space.
flip_v_texcoordtrueFlip V texture coordinate output for common OBJ/DCC expectations.
enforce_outward_windingtrueEvaluate winding direction and flip surfaces when confidence favors outward normals.
manifold_onlytrueFilters to manifold-friendly triangle sets where possible.
remove_enclosed_facestrueAttempts to discard enclosed/internal shell faces during topology cleanup.

Selection Model

  • The plugin collects selected scene nodes, then filters nested selections so child nodes under another selected root are not exported twice.
  • The file dialog is built once and used after selection collection succeeds.
  • No FileSystem context action exists for this plugin; it is scene-selection-driven.

Output Behavior and Caveats

  • The exporter is geometry-only. Skeletons, animation, script state, and gameplay nodes are not preserved.
  • Material handling is good enough for scene inspection and DCC round-tripping, but it is still constrained by what Godot material data exposes cleanly.
  • Texture paths written into MTL content are normalized from resource paths; treat them as pipeline hints, not a cross-DCC guarantee.
  • manifold_only and remove_enclosed_faces are cleanup heuristics, not formal mesh repair certification.
