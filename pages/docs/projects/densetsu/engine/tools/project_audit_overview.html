Project Audit is a review-first utility for finding unused project files. It does not delete anything by itself. It scans trackable resources, builds a dependency graph from project roots, and reports resources that are present but unreachable from those roots.

Operator Flow

  1. Open the Project Audit bottom panel.
  2. Run Scan to collect all trackable files and all reachable dependencies from project roots.
  3. Review the tree of reported unused files inside the panel.
  4. Use Copy to move the report into notes or chat, or Save to write a text report into the project.

Operational Guidance

Review-first rule: an audit result is a cleanup lead, not deletion permission. Files can still be intentionally parked, dynamically loaded in unconventional ways, or used by out-of-band tooling.

Coverage rule: the audit only knows about what becomes reachable from the configured roots and what Godot reports through ResourceLoader.get_dependencies().
