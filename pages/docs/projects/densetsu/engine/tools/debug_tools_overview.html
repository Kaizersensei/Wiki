This page is the operator-facing hub for the current internal plugin documentation wave. The inventory page tracks the whole engine documentation program; this page only routes you to the internal tool pages that have been verified from source in the current pass.

How To Use These Pages

  • Start with an overview page when you need to know what a tool is for and whether it is the right one.
  • Open a workflow or action page when you need the exact click path, selection requirements, or output expectations.
  • Open an implementation reference page when you need helper coverage, settings tables, missing-source notes, or background behavior.
