Debug Tools Overview

Overview

Debug tooling is supplied through editor plugins and helper scenes. The evidence set includes combat collider tooling, mesh extraction helpers, and visualization scenes.

Tool suite

  • addons/densetsu_tool_suite/plugin.gd — editor plugin entrypoint.
  • Helpers: arraymesh_extract_helper.gd, fbx_anim_persist_helper.gd, image_transform_helper.gd, mesh_obj_helper.gd.

Combat collider tools

  • addons/addons/combat_colliders/plugin.gd
  • combat_collider.gd, hitbox_manip.gd, hurtbox_manip.gd

Visualization helpers

  • addons/dynamic_day_night_cycles/eot_plot.tscn
