Recommended Workflow

  1. Select the target Terrain3D or mesh-bearing Node3D, then use the dock to copy that selection into the target path.
  2. Set the output name so the generated content lands under a predictable root.
  3. Add placeable meshes or packed scenes into the mesh pool and confirm the size-group preview looks reasonable.
  4. Start with a small sample area and conservative density to validate orientation, bury depth, and overlap rules.
  5. Only switch to MultiMesh output after the placement pattern itself looks correct.

Parameter Notes

Parameter familyWhat to watchCommon failure mode
Slope windowKeep slope_min and slope_max wide enough for the target surface type.No placements because all samples fail slope tests.
Height windowUse when a terrain should only populate above or below a given altitude band.Unexpected empty areas if target elevation units are misunderstood.
Bury and scaleValidate with just a few placements first.Assets float or sink because source pivots are not centered at the desired contact point.
Collision maskOnly relevant when blocker overlap checks are enabled.Placements pass through blockers if the wrong layers are being tested.
Group tuningUse after pool bounds look trustworthy.Large assets disappear or cluster too aggressively when size grouping does not match the art set.
Material filterUse only when the target is Terrain3D or material IDs are known.No placements because the requested ID or filter mode never matches the sampled terrain data.

Output Modes

ModeGood forTradeoff
Per-instance outputManual cleanup, per-item editing, validating transformsMore scene nodes and more editor overhead on dense passes.
MultiMesh outputDense repeated placement once the pattern is approvedHarder to hand-edit individual placements.

Troubleshooting

SymptomLikely causeWhat to verify
Nothing gets placedTarget path is wrong, mesh pool is empty, or filters reject every sampleConfirm target exists, pool has entries, and slope/height/material windows are not too restrictive.
Placements hover or sink badlySource mesh origin is wrong or bury values are too aggressiveInspect the original mesh pivot before changing placement math.
Dense clusters look unnaturalCluster overlap and clearance settings are too looseRaise clearance radius or cluster multipliers, then retest on a small area.
Terrain-only filter seems broken on mesh targetsMaterial filtering is built around Terrain3D material IDsDisable material filter when sampling non-Terrain3D geometry.
Generated output is hard to editMultiMesh mode was enabled too earlySwitch back to per-instance output until the placement recipe is stable.
Preset values do not appear to stickPreset was not saved or the state file was not updated yetUse explicit Save preset, then refresh the preset list and confirm persistence.
