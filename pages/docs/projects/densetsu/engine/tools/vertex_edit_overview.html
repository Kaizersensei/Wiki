Densetsu Vertex Edit is a focused in-editor mesh-adjustment tool for MeshInstance3D nodes. It adds a dock, samples a limited number of editable vertices as gizmo handles, and lets the user save the resulting mesh resource as .tres or .res.

When To Use It

  • Minor local mesh corrections that are faster than leaving Godot for a DCC tool.
  • Quick scene-blockout adjustments on props or simple geometry.
  • Cases where you only need to touch one mesh surface and can work with sampled handles rather than every vertex at once.

Workflow

  1. Select a MeshInstance3D in the scene.
  2. Choose the target surface and max handle count in the dock.
  3. Enable editing for the selected node if auto-enable did not already do it.
  4. Drag gizmo handles in the 3D view.
  5. Use Save Edited Mesh to write the edited mesh resource out as .tres or .res.

Primary Controls

ControlWhat the user changesWhy it matters
SurfaceWhich mesh surface gets editedWrong surface means missing or unexpected handles.
Max HandlesHow many vertices can become handlesHigher values give more precision but can be heavier in the editor.
Auto-enable on selectionWhether selected meshes immediately become editableConvenience versus more deliberate enabling.
Enable Selected/Disable SelectedExplicitly toggle editing on the active mesh nodeUseful when comparing editable versus non-editable states.
Save Edited MeshPersist the current edited mesh resourceEdits are not useful long-term unless saved and then re-assigned where needed.

Limits

  • Only MeshInstance3D nodes are supported by the current plugin.
  • The tool samples handle candidates instead of exposing every vertex on dense meshes.
  • The save flow writes a mesh resource, not a full scene replacement or import rewrite.
