Densetsu Tool Suite Overview

Content status: Populated from rewrite notes. This page should split into dedicated subpages once menu labels stabilize.

At a glance

  • Plugin path/config: res://addons/densetsu_tool_suite and res://addons/densetsu_tool_suite/plugin.cfg.
  • Project-owned editor plugin; active central utility menu/context-menu hub.
  • Hosts terrain baking, texture helpers, mesh/object helpers, image transforms, selection helpers, static packing, and import-standard actions.

How it works

  • Tools are exposed via editor menu entries and context actions instead of separate single-purpose docks.
  • Companion map generation access points are routed through Tool Suite workflows.
  • Terrain blend baking now synthesizes UV-space output instead of viewport-capturing lit scene pixels.
  • Bake detection supports slope/altitude shader usage across ShaderMaterial resources, overrides, and mesh-bearing Node3D targets.
  • Bake output scaling supports 1x/2x/4x using the largest source texture as the reference.

Interfaces

  • Implementation: res://addons/densetsu_tool_suite/plugin.gd.
  • Helpers: res://addons/densetsu_tool_suite/helpers/.
  • Worklog/context: res://docs/production_rewrite_worklog.md.
  • Key areas: terrain blend baking, Terrain3D import standards, companion maps, OBJ helpers, ArrayMesh extraction/subdivision, pivot/selection helpers, static packing, occlusion pruning.

Operational concerns

  • FileSystem refresh/reimport actions were hardened to avoid Godot progress-dialog/deferred-callback errors.
  • Terrain3D image import standards enforce VRAM compression with compress/high_quality = true (BPTC_RGBA), normal-map importer disabled, mipmaps enabled, and no channel packing at this stage.
  • Validation markers: TERRAIN3D_IMAGE_IMPORT_VALIDATION_FAILURE_COUNT=0, TERRAIN3D_IMAGE_IMPORT_PARSE_FAILURE_COUNT=0; companion generator validation also passed after optimization.
