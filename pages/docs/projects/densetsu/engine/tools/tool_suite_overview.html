Densetsu Tool Suite is the central editor utility hub for Densetsu. Instead of shipping one small plugin per task, it exposes a single Densetsu menu tree and a matching FileSystem context-menu layer that dispatches into mesh helpers, texture helpers, baking pipelines, maintenance utilities, build scripts, and git workflows.

Quick Read

  • Use Tool Suite when the task starts from selected scene nodes, selected resources, or a project-wide editor workflow.
  • Use the action catalog when you need the exact menu path, selection requirements, side effects, or settings behind one action.
  • Use the implementation reference when you need helper coverage, exported settings, missing helper gaps, or background job details.

Known Gaps and Caution Flags

Declared helper gaps: terrain3d_image_import_helper.gd, mesh_to_csg_helper.gd, import_sidecar_cleanup_helper.gd, missing_asset_relink_helper.gd, and mesh_flip_normals_helper.gd are referenced from plugin.gd but were missing from the scanned addon tree on 2026-06-09.

Meaning for readers: the actions are still visible and therefore documented, but helper-level implementation notes for those surfaces remain marked source missing.
