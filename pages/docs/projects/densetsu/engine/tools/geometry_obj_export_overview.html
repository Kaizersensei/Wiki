Densetsu Geometry OBJ Export is a scene-selection-driven export utility for snapshotting selected geometry into OBJ/MTL form. It is designed for DCC round-tripping, inspection, repair, and external processing, not for preserving the full Godot scene contract.

What It Exports

  • MeshInstance3D content under selected roots.
  • CSGShape3D trees, baked into exportable geometry first when enabled.
  • MultiMeshInstance3D content when the plugin option include_multimesh is enabled.
  • Material assignments via generated .mtl output.

What It Does Not Preserve

  • Scripts, gameplay nodes, signals, scene ownership, or editor-only metadata.
  • Skeletons, animation logic, or runtime relationships outside exported geometry transforms.
  • A guarantee that all downstream DCC tools will interpret the generated MTL data identically.

Operator Flow

  1. Select one or more top-level scene roots.
  2. Run the export command from Tools > Densetsu.
  3. Choose an output .obj path in the file dialog.
  4. Review the generated OBJ and companion MTL in your DCC tool or inspection flow.

User-Visible Options

OptionWhy a user would change it
include_mesh_instancesNormally stays on; only disable if you are isolating other geometry types.
include_csgDisable if you want to exclude CSG-authored geometry from the export.
include_multimeshEnable when repeated scatter content must be exported too.
apply_world_transformDisable only if local-space output is required by a custom downstream workflow.
flip_v_texcoordKeep enabled for typical OBJ expectations unless a downstream tool proves otherwise.
enforce_outward_windingUseful when imported geometry has inconsistent face orientation.
manifold_onlyUse when cleaner triangle topology matters more than retaining every surface.
remove_enclosed_facesUse when internal shells are not useful to the downstream step.

Caveats

Snapshot tool: this is best treated as geometry export, not scene serialization.

Heuristic cleanup: winding correction and enclosed-face cleanup are best-effort heuristics, not formal mesh certification.
