Densetsu Geometry OBJ Export

Content status: Populated from local plugin notes. Menu-path screenshots and round-trip examples are pending DCC workflow finalization.

At a glance

  • Project-owned editor plugin at res://addons/densetsu_geometry_obj_export.
  • Exports selected scene geometry to Wavefront OBJ for DCC repair, inspection, and external processing.
  • Status: active utility; intended as geometry snapshot/export tooling.

How it works

  • Select one or more scene roots and run the exporter from the plugin UI/workflow.
  • Exporter walks nested MeshInstance3D under selected roots.
  • CSGShape3D trees are baked before export.
  • MultiMeshInstance3D is expanded into regular geometry for OBJ output.
  • Surface material grouping is preserved with generated .mtl output.

Interfaces

  • Plugin path: res://addons/densetsu_geometry_obj_export.
  • Plugin config: res://addons/densetsu_geometry_obj_export/plugin.cfg.
  • Local docs: res://addons/densetsu_geometry_obj_export/README.md.

Operational concerns

  • This exporter is snapshot-oriented and not a full gameplay scene serializer.
  • It does not preserve skeletons, animation, gameplay nodes, or runtime behavior.
  • Use it for geometry transfer/inspection, then re-integrate results through project authoring flows.
