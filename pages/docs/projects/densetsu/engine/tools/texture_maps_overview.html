Densetsu Texture Maps is an internal toolchain component, not a standalone editor plugin in this documentation wave. Its job is to generate and clean up companion texture maps behind Tool Suite actions.

User Touchpoints

TouchpointWhat the user seesBacked by
Generate Missing Companion MapsSelection or current-folder recursive generation from Tool Suitegenerate_for_paths() with only_generate_missing = true
Generate All Companion MapsSelection generation from Tool Suitegenerate_for_paths() with only_generate_missing = false
Cleanup Orphan Companion MapsSelection or folder cleanup from Tool Suitecleanup_orphan_companion_maps_for_paths()
Cleanup All Companion MapsSelection or folder cleanup from Tool Suitecleanup_all_companion_maps_for_paths()

Operational Guidance

Not a plugin UI: document this as a Tool Suite dependency, not as a separate dock workflow.

Cleanup caution: the cleanup entrypoints are destructive when delete_files is true. Treat them as reviewed cleanup steps, not casual maintenance clicks.
