Densetsu Texture Maps

Content status: Populated from production rewrite notes. Final parameter guidance and approved example outputs are pending.

At a glance

  • Project-owned helper module at res://addons/densetsu_texture_maps (no currently active plugin config).
  • Generates companion maps from source images inside Godot: normal, ambient, specular, and displacement.
  • Status: integrated helper code exposed through Densetsu Tool Suite menus.

How it works

  • Standalone dock workflow was removed; features are now routed through Tool Suite texture menu entries and FileSystem context actions.
  • Batch processing includes bounds/safety limits to avoid long editor hangs on huge recursive runs.
  • Large images are constrained by tool defaults before processing.
  • Algorithm path avoids slow per-pixel Image.get_pixel()/Image.set_pixel() hot loops.

Interfaces

  • Module path: res://addons/densetsu_texture_maps.
  • Implementation entrypoint: res://addons/densetsu_texture_maps/texture_map_generator.gd.
  • Validation gate: res://temp/validate_companion_generator.gd with last documented value COMPANION_GENERATOR_VALIDATION_FAILURE_COUNT=0.
  • External reference: NormalMap-Online.

Operational concerns

  • Ambient/specular/displacement outputs use L8 grayscale buffers; normal output remains RGBA8.
  • The tool is inspired by NormalMap-Online behavior but implemented as a local Godot batch tool, not an embedded web app.
  • Refer to res://docs/production_rewrite_worklog.md for rewrite notes and rollout context.
