Overview

This section documents the Densetsu authoring-data model and the editor or database layer being built to support it. The repo docs describe the target Authoring workspace, the target SQLite taxonomy, and the biome compiler direction. The addon code shows which part of that plan is already real in the project.

What This Section Covers

  • The target Authoring workspace: shared context, module rail, report strip, sidecar orchestration, and compile flow.
  • The current Densetsu Authoring addon: workspace shell, SQLite service layer, migrations, repositories, and scene-policy scaffolding.
  • The migration path from early scaffold to a database-first authoring workflow that stays compatible with Godot assets and Terrain3D.

Pages In This Baseline

  • Authoring Database Overview - current architecture, schema coverage, dependencies, and verified implementation status.
  • Authoring Pipeline - current workspace flow, planned compile flow, and where the live code stops today.
  • Actor Capabilities - target capability taxonomy and the schema foothold added for entity capabilities.
  • Asset Registry - target asset catalog rules and the current asset-registry or material-profile footing.
  • Placement Rules - the planned biome, topology, and generation rule layer above Terrain3D and authored assets.
  • Generated Chunk Records - deterministic generation record expectations and current compile-scaffold limits.
  • World-State Overlays - variant-switch and suppression rules for story, environmental, and temporal world changes.

Status

Partially implemented. The authoring workspace shell, context model, migration runner, repositories, and a growing schema are implemented. Most of the full cataloguing and compile model described in the repo docs remains target architecture and should be read as planned state, not completed engine behavior.
