Overview

This section documents the Densetsu authoring-data model and the editor/database layer being built to support it. The handout defines the intended taxonomy. The codebase defines the current implementation slice. Pages in this section must make that distinction obvious.

What This Section Covers

  • The target Authoring DB taxonomy: entities, actors, capabilities, asset references, placement rules, overlays, and generated records.
  • The current Densetsu Authoring plugin: workspace shell, SQLite service, migrations, repositories, and scene-policy scaffolding.
  • The migration path from early scaffold to a database-first authoring workflow that stays compatible with Godot assets and Terrain3D.

Pages In This First Baseline

  • Authoring Database Overview - current architecture, schema, dependencies, and verified implementation status.
  • Authoring Pipeline - current workspace flow, planned compile flow, and where the live code stops today.
  • Actor Capabilities - target capability taxonomy and the current lack of actor-capability schema support.
  • Asset Registry - target asset catalog rules and the current material-profile foothold.
  • Placement Rules - the planned biome/topology rule layer above Terrain3D and authored assets.
  • Generated Chunk Records - deterministic generation record expectations and current compile-scaffold limits.
  • World-State Overlays - variant-switch and suppression rules for story, environmental, and temporal world changes.

Status

Partially implemented. The authoring workspace shell, context model, migration runner, and a small schema are implemented. Most of the cataloguing system described by the handout remains target architecture and is documented as such in this section.
