Overview

Data & Authoring covers resource schemas, data assets, and the editor-side tooling used to author and validate them. Evidence includes resource classes in engine/data/resources and the Densetsu tool suite addons.

Scope

  • Data asset directories (data, data3d)
  • Editor tooling and helpers for authoring data
