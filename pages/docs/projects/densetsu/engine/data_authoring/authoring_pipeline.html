Authoring Pipeline

Overview

The authoring pipeline relies on editor tooling bundled in the Densetsu tool suite and other addons. These helpers automate mesh extraction, animation import persistence, and image transformation.

Key tools

  • addons/densetsu_tool_suite/plugin.gd — editor plugin entrypoint.
  • arraymesh_extract_helper.gd — mesh extraction helper.
  • fbx_anim_persist_helper.gd — animation import helper.
  • image_transform_helper.gd — image path transform helper.
  • mesh_obj_helper.gd — mesh export helpers.

Related addons

  • addons/goshapes samples and tools.
  • addons/dynamic_day_night_cycles sample scenes.

Status

Implemented. Tooling scripts and helper scenes are present.
