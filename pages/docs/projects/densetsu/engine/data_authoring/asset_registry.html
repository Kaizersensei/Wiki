The asset registry is meant to catalog references to project assets, not replace Godot's asset pipeline. Files remain files. The authoring database tracks stable IDs, metadata, ownership, validation status, and cross-record relations. Today, the only concrete registry slice is external material profiling.

Target Role In The Authoring Model

  • Register models, materials, textures, scenes, animations, audio, VFX, UI assets, and reference art by stable authored IDs.
  • Store metadata such as owner domain, import status, license state, author, and notes.
  • Support validation and cross-linking without moving binary content into SQLite.

Implementation Gap

Current truth: the project already has a useful registry foothold for scene materials, including usage indexing and DB sync.

Current limit: there is no generalized asset registry table or editor flow yet for models, textures, scenes, audio, VFX, or UI assets.
