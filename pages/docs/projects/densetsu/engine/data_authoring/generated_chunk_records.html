Generated chunk records are the project-owned evidence of deterministic world generation. The handout is explicit: Densetsu should not depend on opaque random scatter near the player. Authoring data, terrain data, and a seed should resolve into reproducible generated output with stable identities and explainable reasons.

Deterministic Model

  1. Authoring records define the allowed outputs and their conditions.
  2. Terrain and semantic context provide the substrate and local facts.
  3. A compile or generation pass resolves the result from those inputs plus a seed.
  4. The runtime loads generated results as stable authored world content, not as fresh random rolls.

What Needs Stable Identity

Generated content type Identity expectation
Visual-only clutter batchesCan be stored as deterministic batch output without per-object gameplay identity.
Interactive plants, resources, hazards, or densNeed stable generated object IDs for save-state, locking, deletion, or manual conversion.
Quest-relevant generated objectsNeed traceable, explainable records and strong validation.
