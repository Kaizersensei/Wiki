The Densetsu Authoring database is intended to become the structured knowledge layer for authored game content. Today, the implementation is only a first slice: the workspace shell can probe a project-owned SQLite path, run migrations, and expose a few repositories, but the full authoring taxonomy from the handout is not yet present in schema or UI.

Current Architecture

Layer Current role Notes
Workspace shellauthoring_workspace.gd shows DB status and can trigger initialization.Acts as the current operator entry point.
Database serviceauthoring_database_service.gd owns path, backend selection, status refresh, and repository creation.Central service boundary for the current addon slice.
Backendsqlite_authoring_database_backend.gd expects the SQLite class from godot-sqlite.Blocked until the dependency exists in the project tree.
Migrationsmigration_runner.gd applies sorted .sql migrations and records versions.Creates a repeatable schema bootstrap path.
RepositoriesBiome and material-profile repositories are currently implemented.No repositories yet for actors, overlays, placement rules, or generated records.

Implemented Schema Today

Table Purpose Current status
biomesFirst semantic-domain foothold for biome records.Queryable through BiomeRepository.
material_profilesCatalog of external scene materials synced from the Material Tracker backend.Most concrete asset-registry foothold in the current build.
water_systemsReserved authoring table for water-system records.Defined in schema but not surfaced through a repository or editor view.
map_assignmentsLightweight mapping between map path, domain, and target ID.Useful foothold, but not a placement-rule system.
compiler_reportsReserved table for compile and validation output.No full compile pass writes are implemented yet.
schema_migrationsMigration bookkeeping created by the runner.Internal support table rather than authored content.

Dependency State

Verified blocker: the addon code expects res://addons/godot-sqlite/gdsqlite.gdextension, but that addon is not present in the scanned densetsu-dev tree.

Effect: the database path and migration flow are real, but a working SQLite backend cannot be assumed in this snapshot.

Concern Target model Current slice
