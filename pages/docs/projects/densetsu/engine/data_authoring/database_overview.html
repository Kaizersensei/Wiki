Database & Data Model Overview

Overview

The data layer is built around custom Resource schemas and data assets stored in data/ and data3d/. These resources define AI profiles, biomes, collisions, factions, items, and other gameplay data.

Resource schema

  • AIProfileData
  • BiomeData
  • CollisionData
  • FactionData
  • ItemData

Asset locations

  • data/ — core data assets.
  • data3d/ — 3D-specific data assets (camera, items, prefabs, movement).

Status

Implemented. Resource schemas and sample assets exist.

Sources

  • engine/data/resources/*.gd
  • engine3d/data/resources/*.gd
  • data3d/ resources
