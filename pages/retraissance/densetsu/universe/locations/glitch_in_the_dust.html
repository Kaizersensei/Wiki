Glitch in the Dust

Overview

Side-quest anomaly site with a flickering rift and a lone spinning arcade machine in a dusty shrine.

Encounter

  • Activating the machine summons Bimmy (corrupted memory gunslinger) in a puff of digital smoke.
  • Tied to “Echo Worlds” created by Time Fan overuse/damage; Bimmy persists only while the anomaly is stable.

Role

Represents lost arcade-era memory bleeding into the world; fits time-glitch theme and offers temporary ally or fight set-piece.
