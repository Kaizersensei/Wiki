# World Memory vs. Infinitree Timeline Log

- **World Memory**: sealed memories captured from one or more individuals about a specific thing. Subjective and tied to the witness’ perspective.
- **Infinitree Timeline Log**: unbiased record of events as they occurred. Stores timeline facts rather than any viewer’s perception.

Key implication: recovering World Memory reveals how someone perceived an event; accessing the Infinitree Timeline Log reveals what actually happened. Both are required to reconcile discrepancies.
