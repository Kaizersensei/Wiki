# Cosmology & Epochs

The world exists across layered temporal strata rather than a single linear history.

## Epochs
- **Before Eclipse (BE)**: mythic, unstable, partially overwritten
- **After Eclipse (AE)**: stabilized but fractured reality

The Great Eclipse is the only absolute cosmological constant.

## Cosmological Model
- Time behaves as an ecosystem
- Space retains memory
- Certain locations exist in overlapping states

The cosmos favors balance through correction, not prevention.
