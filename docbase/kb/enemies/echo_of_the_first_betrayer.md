# Echo Of The First Betrayer

## Summary
Dark/time echo that replays the first betrayal in loops. Mirrors trust actions, then backstabs; weak to truth/clarity (light, vows, memory anchors). Phase shifts when its scene is interrupted.

## Known facts
- Replays betrayal scene; punishes “cooperate” choices unless resolved correctly.
- Phase shifts on interruption; mirrors player actions.
- Weak to light/truth items; “confront” state opens bigger damage windows.
