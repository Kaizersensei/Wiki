# False Heaven

## Summary
Floating anomaly citadel built from discarded dreams; lures entrants with false solace and strips memories/skills. Light/Dark + Mind aligned; weak to memory anchors and mind-wards.

## Known facts
- Causes memory loss; projects “safe haven” illusions.
- Zone hazard: erodes learned abilities over time.
- Weakness: anchoring memories (tokens, vows) and mind-ward rites.
